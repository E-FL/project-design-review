# Morrow fictional example

All products, identities, metrics and screens here are invented. Platform labels demonstrate simulated captures, not native-device validation. External Stitch/Claude choices are explicitly simulated references. No agent worker is connected.

From the repository root run `python scripts/create_demo.py <new-folder>`, then start `node review-server.mjs` inside it. The generator copies the shared starter and only this fictional data, seeds one demonstration flag, and prepares matching Full explanations for P01-r3. Existing private feedback, queues and worker credentials are never copied.

Provider and Customer belong to the Morrow project; Shared contains the shared account example. Five pages have three preserved iterations with platform/theme comparisons. Hebrew is offered as a missing-evidence example; English captures are not relabeled Hebrew.
